# Calculator

A simple calculator that runs in any browser. One file, no installation, no libraries.

- Add, subtract, multiply, divide, percent, change sign, decimals
- Works with touch and with the keyboard (digits, `+ - * /`, `Enter`, `Backspace`, `Esc`)
- Light and dark mode follow the device setting
- Dividing by zero shows `Error`

## Run it

Open `index.html` in a browser.

## Put it online (GitHub Pages)

1. Upload `index.html` to a GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, pick the `main` branch and the `/ (root)` folder, then **Save**.
4. After a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.
